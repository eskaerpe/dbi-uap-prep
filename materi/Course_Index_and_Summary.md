### Session 7: Functions
**File:** `Session_7_Functions.md`

**Topics Covered:**
- Defining functions with parameters
- Passing arguments (positional, keyword, default, *args, **kwargs)
- Return values (single and multiple)
- Passing lists to functions
- Function best practices
- Common function patterns

**Learning Outcomes:** LO 3 - Demonstrate algorithms using Python syntax

### Session 8: File and Exceptions
**File:** `Session_8_File_and_Exceptions.md`

**Topics Covered:**
- Working with multiple Python files and modules
- Writing to files (modes: w, a, x)
- Reading from files (entire file, line-by-line, into list)
- Exception handling (try-except-finally-else)
- Common exception types
- File operations best practices
- Practical examples (CSV handling, file copying)

**Learning Outcomes:** LO 3 - Demonstrate algorithms using Python syntax

---

### Session 9: Classes in Python
**File:** `Session_9_Classes_in_Python.md`

**Topics Covered:**
- Object-oriented programming (OOP) principles
- Class definition and structure
- Creating objects (instantiation)
- Instance and class variables
- Methods (instance, class, static)
- Encapsulation and access control (public, protected, private)
- Special methods (__init__, __str__, __repr__, __len__, __getitem__, __eq__)
- Properties and decorators
- Practical examples (library system, bank accounts)

**Learning Outcomes:** LO 4 - Select the best algorithm in problem solving

---

### Session 10: Searching and Sorting in List
**File:** `Session_10_Searching_and_Sorting.md`

**Topics Covered:**
- **Searching Algorithms:**
  - Linear search (O(n))
  - Binary search (O(log n))
  
- **Sorting Algorithms:**
  - Bubble sort (O(n²))
  - Selection sort (O(n²))
  - Insertion sort (O(n²))
  - Quick sort (O(n log n) average)
  - Merge sort (O(n log n) guaranteed)
  
- Built-in Python sorting (sorted(), .sort())
- Algorithm complexity analysis
- Practical examples and comparisons

**Learning Outcomes:** LO 4 - Select the best algorithm in problem solving
